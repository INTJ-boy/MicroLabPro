# MicroLab Pro 🦑

A free, offline-capable toolkit for microbiology students, lab technicians, and quality control professionals. Built by a Master's student in Microbiology and Quality Control (USTHB, Algeria).

## Tools

- **MicroID** — Step-by-step biochemical decision tree for bacterial identification (200+ species)
- **MicroPath** — Antibiogram interpreter (CASFM/EUCAST), culture media recommendations, food QC verdicts
- **MicroCalc** — Lab calculators: CFU/g correction, MPN tables, sampling plans (n/c/m/M), D/Z values, dilution series
- **MicroPedia** — Reference library: culture media encyclopedia, staining protocols with visual step-by-step guides, ISO norms, practice quiz
- **MicroSteril** — Sterilization and disinfection reference: autoclave cycles, disinfectant dilution calculator, dry heat/UV parameters

## Features

- Fully trilingual: French, English, Arabic (with RTL support)
- No login, no backend, no tracking — pure static site
- Dark/light theme, offline-capable
- Favorites, daily practice quiz, unit converter, printable cheat sheets

## Tech

Plain HTML/CSS/JavaScript. No build step, no dependencies. Deploy anywhere that serves static files.
